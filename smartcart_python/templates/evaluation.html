Model Technical Architecture

Feature Extraction

Scikit-learn TfidfVectorizer with 1-to-2 n-gram range and sublinear Term Frequency scaling: tf_scaled = 1 + log(tf).

Similarity Formulation

Pairwise Cosine Similarity: cos(u, v) = (u · v) / (||u|| ||v||) across normalized sparse TF-IDF vectors.

Performance Optimization

Persistent vector matrix caching in memory to ensure sub-millisecond real-time retrieval without re-fitting per query.
